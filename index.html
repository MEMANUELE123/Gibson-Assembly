Gibson Assembly Primer Designer

Design chimeric primers for a two-fragment Gibson Assembly (vector + insert). Calculates nearest-neighbor Tm for annealing regions and homology overlaps, flags length/GC/dimer issues, and gives you ready-to-order sequences.

1 Vector (backbone)

Paste the vector exactly as you have it — full plasmid, any starting position, unedited. Below, tell the tool where the insert goes and it will rotate/slice the sequence for you.

Both boxes use the base numbering of the sequence you pasted above (position 1 = the first base you pasted). For a clean single-site insertion with nothing removed, make the second number exactly one more than the first (e.g. 2145 and 2146). To replace a dropout/stuffer fragment (like a CcdB or lacZ cassette), enter the bases immediately flanking it — everything between them is dropped and replaced by the insert. Leave both blank only if you've already manually rearranged the vector sequence to start right after the insertion site and end right before it.

Also design primers to PCR-linearize this vector Leave unchecked if you'll linearize the vector by restriction digest. Check this if you'd rather PCR it out — the tool will design a plain (tail-free) primer pair at the same two cut positions above.

2 Insert

Paste the exact region you want cloned in (the amplicon), 5'→3', in the orientation you want it to appear in the final plasmid.
